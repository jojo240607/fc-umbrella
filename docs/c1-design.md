## 4. 标称状态递推（★关键差异：比力进**动力学**）
```
q ← q ⊗ exp((ω_m − b_g)·dt)
v ← v + (R(q)·(a_m − b_a) + g_ned)·dt        ★ 比力驱动动力学（非重力参考 ✓）
p ← p + v·dt
b_g, b_a ← 常值（随机游走）
```
⇒ **由此，"比力被加速度污染"的问题不存在** ✗✓（那正是现架构所有门控要打的补丁 ✓）
