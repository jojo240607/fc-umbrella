## 4. 标称状态递推（★关键差异：比力进**动力学**）
```

> ★**乘法顺序警告（2026-09-21 数值判定 ✓，同类陷阱第 2 例 ✗）**：
> 标准文献常写 `q ← q ⊗ exp(ω·dt)`（Hamilton/机体速率的右乘 ✓），

> （由 §12.4 的"左乘 = 机体(local)扰动"直接推出 ✓，并已数值确认 ✓）
p ← p + v·dt
b_g, b_a ← 常值（随机游走）
```
⇒ **由此，"比力被加速度污染"的问题不存在** ✗✓（那正是现架构所有门控要打的补丁 ✓）

## 5. 误差状态动力学 F —— ★**不得手写** ✗
```
δθ̇ = 【+[ω×]】·δθ − δb_g          ← ★已修正（原文写 −[ω×]，经数值工装证伪 ✗）
δv̇ = −R·[a×]·δθ − R·δb_a
δṗ = δv          δḃ_g = 0          δḃ_a = 0
```

**★为何是 `+`（推导）**：本项目 local 扰动为 `q = δq * q̂`（§12.4 数值判定 ✓），

⇒ `δθ' = R(w·dt)δθ ≈ δθ + [ω×]δθ·dt` ⇒ **A = +[ω×]** ✓✓（与数值一致 ✓）
**硬要求（来自 §14.11 发现① ✓）**：
- 参照实现用**符号生成**（`sym::PredictCovariance` ← `python/ekf_derivation/derivation.py` ✓）
