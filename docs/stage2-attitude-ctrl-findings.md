# 阶段 2 姿态控制内环：实测发现记录

> 场地：H 场（`fly-sim-core` + `PhySdkWorld` 真实物理引擎）。
> 复现：`cd fly-simulater && cargo test -p fly-sim-core --test att_ctrl -- --nocapture`

## 2.0 测试基座与一个接口缺口

**原代码没有独立的姿态环入口**：`q_des` 只由位置/速度外环在 `PidController::control()`
内部生成（`pid.rs`：`tilt_n = clamp(acc_n/g, ±tilt_max)` → `q_des = from_euler(...)`）。
而阶段 2 的核心需求是"**先用真值姿态验证控制器本身**，再接入估计姿态"——
没有入口就无法隔离。

**处置**：把 `control()` 尾部（`omega` 低通 → `attitude_rates` → `x4_mix` → 限幅）
**纯提取**为 `PidController::control_attitude(dt: Second, q_des, des_thrust, est)`；
`control()` 内部改为调用它。**行为逐位不变**（由 `flyctrl-core` 101 项回归守护）。

**隔离手段（本阶段所有测试）**
- **完美估计器**：`QuadrotorPlant::state_ned()` 真值**直喂**控制器 → 估计误差不参与
- **只驱动内环**：`control_attitude`，不经任何外环
- **高度保持**：`thrust = hover / cos(tilt)`（否则一倾斜即掉高 → 死亡螺旋）

**实测链路事实**：链路为 `q_des → P-D(att_kp=3.0, att_kd=0.3) → 期望机体角速率
→ x4_mix → 电机`。**没有独立速率 PID**（角速率指令直接进混控），
且**整条姿态路径没有任何积分作用**。

## P2. 姿态路径**没有积分作用** —— 但实测证明**不需要**

### 2.2b 静刚度实测（常值力矩 → 稳态姿态误差）

真值姿态闭环，目标水平，逐步施加常值世界系力矩 `τ`（每步冲量 `τ·dt`），
把 τ 换算成**等效重心偏移** `d = τ/(m·g)`（`m·g = 11.77 N`）：

| τ(N·m) | 等效重心偏移 | e_ss(°) | 静刚度 K(N·m/°) |
|---|---|---|---|
| 0.0020 | 0.17 mm | 0.012 | 0.1739 |
| 0.0050 | 0.42 mm | 0.029 | 0.1740 |
| 0.0100 | 0.85 mm | 0.057 | 0.1741 |
| 0.0200 | 1.70 mm | 0.115 | 0.1745 |
| 0.0500 | 4.25 mm | 0.285 | 0.1756 |
| 0.1000 | 8.49 mm | 0.563 | 0.1775 |
| 0.2000 | 16.99 mm | 1.104 | 0.1812 |

**K ≈ 0.174 N·m/°**（线性区内恒定）。换算成真实扰动量级：

| 真实扰动 | 永久姿态误差 |
|---|---|
| 1 mm 重心偏移 | 0.07° |
| 5 mm 重心偏移 | 0.34° |
| 10 mm 重心偏移 | 0.68° |
| 1% 电机推力不一致 | 0.04° |

### 结论：**姿态环不必加积分**

真实量级的静态扰动（重心偏移 ≤10mm、电机不一致 ~1%）造成的永久误差 **< 1°**。
对比定高/位置通道（那些环已经有 `iz` 等积分），姿态通道的静差可以接受。

> 注：无积分 P-D 对双积分对象**理论上阶跃跟踪静差为 0**；实测的阶跃静差
> （`err ≈ 0.12° + 3.2%×指令`，见 P1 数据）**不是控制刚度不足**，而是
> **倾斜飞行时旋翼阻力矩（rotor drag / H-force 偏心）造成的真实气动载荷**——
> 它与倾斜角（≈侧向速度）成比例，所以表现为"3.2% 增益误差"的外观。

## P3. 增益图谱：稳定域是**窄带**，且**提高 `att_kd` 会失稳**

### ⚠️ 对上一版 P3 的**自我纠正**

上一版结论是"`att_kd` 偏小 → 应提高"。**这是错的。** 扫完二维图谱（`att_gain_grid_stability_and_damping`，roll 阶跃 15°，真值姿态闭环，6s）
后发现：**`att_kd` 提到 0.6 以上全面失稳**。

### 图谱（单元：超调% / 尾段振荡%(max−min)；X = 失稳）

| kd\kp | 1.0 | 1.5 | 2.0 | 3.0 | 4.0 | 5.0 |
|---|---|---|---|---|---|---|
| 0.20 | 14.1/0.43 | 9.2/0.21 | **6.9/0.13** | 22.8/0.38 | X 82/153 | X 99/185 |
| 0.30 | 14.0/0.59 | 9.2/0.28 | **6.9/0.15** | 14.1/0.86 | X 63/115 | X 73/134 |
| 0.45 | 13.9/0.85 | 9.2/0.45 | **7.0/0.48** | X 47/81 | X 53/93 | X 58/104 |
| 0.60 | X 17/6 | X 44/63 | X 45/70 | X 46/76 | X 48/83 | X 51/91 |
| 0.80 | X 54/63 | X 49/65 | X 46/66 | X 43/70 | X 45/75 | X 47/82 |
| 1.50 | X 65/68 | X 56/64 | X 57/63 | X 47/64 | X 44/66 | X 44/69 |

> **指标口径教训**：初版用 `tail_peak`（末段最大偏差）判稳，结果**全表皆失稳**——
> 因为它把"系统性偏移"（旋翼阻力矩造成的倾斜静差，约 4.9%）当成了振荡。
> 改用 `tail_osc`（末段 max−min）后才看清真实边界。已加入
> `metrics.rs::StepTrace::{tail_osc, tail_mean}`。

### 三条结论

1. **提高 `att_kd` 不是出路**：`kd≥0.6` 时**全 kp 失稳**。即阻尼受
   **执行器/plant 动态（电机一阶滞后 + 气动阻尼）**限制，出货值 0.3 已接近上限。
2. **`kp≈2.0` 是阻尼甜点**：`kd∈[0.20,0.45]` 下超调稳定在 **~7%（ζ≈0.65）**，
   且对 `kd` 不敏感；而 **出货档 `kp=3.0` 为 14.1%（ζ≈0.53）**。
3. **稳定域是窄带**：`kd≤0.45` **且** `kp≤3.0`（`kd=0.45` 时 `kp=3` 已失稳）——
   出货档已经**贴着边界**。

### 权衡（不能只看阻尼）

由 P2：静刚度 `K ≈ 0.055·att_kp` N·m/°。

| | kp=3.0（出货） | kp=2.0（甜点） |
|---|---|---|
| 超调（ζ） | 14.1%（0.53） | **6.9%（0.65）** |
| 静刚度 | 0.174 N·m/° | 0.11 N·m/° |
| 10mm 重心偏移 → 静差 | 0.68° | 1.07° |
| 姿态环交叉频率 | ≈0.48 Hz | ≈0.32 Hz |
| 距稳定边界 | 近（kd≥0.45 即失稳） | 宽（kd 0.2~0.45 均可） |

→ **降 `kp` 到 2.0 换阻尼与裕度，代价是刚度降 1/3、带宽降 1/3。**
这是一个需要结合位置/速度环一起定的权衡，**不在本阶段单方面改默认值**
（`att_kp` 是跳阶段共享参数，改动必须由阶段 4/5 的判据背书）。

| 指令幅值 | 真值最大 | 估计最大 | 真值尾振% |

### 瞬态证据（t=1.30s 邻域）

```
roll 真值=41.6°  估=16.8°      ← 角度差 25°
omega 真值 p=0.03  估 p=0.09   ← 角速率一致
```

**角速率一致、角度差 25° 恒定** → 误差在更早的瞬态里累积，之后因速率一致而不再变化；
而重力锚的**方向门在误差 ~25° 时接近关闭阈值（25.8°）**，纠不回来
（与 F6「方向门死锁」同一机制）。

### ⚠️ 必须先排除的台架保真度缺口

**2.5 台架直接调 `ekf.step`，绕过了 `step_hil` 的 IMU 预处理
（accel 40Hz 陷波 + 20Hz 低通、gyro 40Hz 陷波）。**
而 F1 修复又把 EKF 自己那级参考低通旁路了 → **锚定当前完全依赖 `step_hil` 的上游预处理**。

所以本结论**在排除该缺口前不能定性为系统缺陷**。下一步：
把 2.5 改走 `HilContext::step_hil`（或复刻同一预处理）后重测。

> F1 把 EKF 的参考量低通旁路后，**重力锚定的抗噪完全依赖 `step_hil` 的上游低通**。

> （或明确文档化该前置依赖）。

## P4 定论：根因是**平移污染重力锚**（阶段 1 的覆盖缺口）

### 2.5c 二分（roll 阶跃 5°，真值姿态闭环对照）

| 组合 | 真值最大 | 真值尾振% | 结论 |
|---|---|---|---|
| 估计角 + 估计速率 | 21.5° | 140.96% | 失稳 |
| **真值角 + 估计速率** | **10.0°** | **1.47%** | ✅ **稳定** |
| **估计角 + 真值速率** | **21.6°** | **142.51%** | ❌ **失稳** |

→ **失稳来自"角估计"，速率估计是干净的。**

### 误差轨迹（估计−真值，每 0.1s）

```
-0.0 -0.3 -3.3 -4.2 -7.8 -8.1 -11.5 -12.5 -14.3 -15.4 -15.8 -16.3
-15.7 -14.9 -13.2 -11.6 -9.1 -7.3 -4.7 -2.5 -1.1 1.2 2.0 3.8
```

**~0.5Hz、幅度达 16° 的低频误差**——而 0.5Hz 正在姿态环带宽内（实测 -3dB≈1.6Hz）→ 被环路放大成耦合振荡。

### 根因：**A3 平移机动（比力 ≠ 重力）**

**阶段 1 的原有用例（A1/A4/A6/A9）`accel_world` 都 ≈0 或纯重力，从未覆盖
"平移加速度污染重力参考"**。补测 A3（真值姿态开环，low_noise）：

| 平移加速度 | 姿态 RMSE | 最大 | \|a\|/g 范围 |
|---|---|---|---|
| 0.2g | **6.10°** | 11.30° | [1.00, 1.02] |
| 0.5g | **14.53°** | 26.53° | [1.00, 1.12] |
| 0.8g | **21.62°** | 38.61° | [1.00, 1.28] |

误差**与平移加速度成正比**，且**全部在 pitch 轴**。

**两条防护都失效**：
1. **幅值门帮不上**：`|a|/g` 最高仅 1.28，远离门限 0.5/2.5 → **从不关闭**。
2. **方向门不足**：0.2g 平移的比力只偏重力 11.3°（门全开）；0.5g 偏 26.6°
   （恰好卡在 25.8° 阈值上）。

→ 重力锚在平移机动中把估计拉向**被平移污染的重力参考**，造成数度到数十度的
姿态误差。陀螺本身是干净的，**全部误差来自锚定**。

### 与 F6 的关系

F6（方向门死锁）与 P4 是**同一个门控机制的两个面**：
- F6：误差 > 25.8° → 门关 → **纠不回来**；
- P4：误差 < 25.8° → 门开 → 锚定把估计**拉偏**。

两侧都说明 **方向门这个单阈值设计在"平移污染"面前不够**。

### 判据已落地

`att_est.rs::a3_brake_reversal_translation_contamination`（**当前为红/立案**）：
平移机动下姿态 RMSE 应 **< 3°**（陀螺干净，锚定不应干扰）。实测 0.2g 就 6.1°。

### 后续方向（待定，属阶段 1 的遗留）

| 方案 | 代价 |
|---|---|
| A. 收紧方向门阈值（如 25.8°→10°） | 小；但会缩短锚定的可用姿态范围 |
| B. 用**陀螺-加速度一致性**判据代替纯角度门（平移时比力变化与角速率不匹配） | 中 |
| C. 用 GPS/Doppler 测得的**世界系加速度**补偿比力（`a_body` 减去平移项）后再锚定 | 大，但最根本 |
| D. 降低锚定强度（`att_alpha`） | 治标，且削弱漂移抑制 |

**建议 C**（若有速度观测）**或 B**（无速度观测时）。

## P4-C：平移补偿（方案 C）—— **oracle 验证通过，收益 97~98%**

### 实现

`EkfEstimator::set_world_accel([f32;3])` + 字段 `world_accel`，
在重力锚定前做：

```
a_comp = a_body − R̂ᵀ · a_world
```

**补偿后的 `a_comp` 同时用于幅值门与方向门** —— 关键点：
`a_comp ≈ R^T(−g)`，其**方向**是真实重力方向、其**幅值**才真正 ≈g，
所以**幅值门也恢复了有效性**（原设计下平移时 `|a|/g` 最高 1.28，门从不关闭）。

默认 `world_accel = [0,0,0]` → **与历史行为逐位一致**（flyctrl-core 101 项回归守护）。

### oracle 收益（补偿源 = 真值 `accel_world`）

| 平移加速度 | 无补偿 RMSE | **补偿后 RMSE** | 改善 |
|---|---|---|---|
| 0.2g | 6.10° | **0.18°** | **97%** |
| 0.5g | 14.53° | **0.27°** | **98%** |
| 0.8g | 21.62° | **0.36°** | **98%** |

→ **方案 C 的收益上界极高**，值得落实生产源。

### 生产源实测（GPS/Doppler 差分）

实现：`update_vel_r` 内对**新鲜**多普勒观测做差分（新鲜判据 = 观测相对上次变化；
GPS 20Hz 而控制 250Hz → 大量重复样本，对重复样本差分只会得 0），
一阶低通 `tau=0.25s` 后写入 `world_accel`。开关 `G_AW_GPS`（**默认 0 = 关**，
保证历史行为逐位不变；flyctrl-core 101 项守护）。

> 注：它曾在阶段 4 一度被改为**默认开启**（P13/P14），但 **2026-09-21 晚的全场景
> 评估推翻了该结论**（自由落体下会把幅值门的失重保护骗开 → 姿态发散），已改回
> 默认关闭。详见 `docs/stage1-attitude-findings.md` 末尾的定案段。

| 平移加速度 | 无补偿 | **GPS 差分** | oracle(上界) | GPS 改善 | oracle 改善 |
|---|---|---|---|---|---|
| 0.2g | 6.10° | **2.92°** | 0.18° | 52% | 97% |
| 0.5g | 14.53° | **5.64°** | 0.27° | 61% | 98% |

## P4 最终结论：早期"剧烈失稳"大部分是**台架非代表性**

### ⚠️ 又一次口径教训（与 P3 的 `tail_peak`、F6 的 yaw 累计同类）

2.5 早期台架把 15° 倾角**恒定保持 6s** ⇒ **持续侧向加速**（v≈16 m/s、位移≈47m）
⇒ 进入强气动工况。这**不是真机工况**（位置环会把飞行器留在悬停附近）。
它给出"177% 超调 / 41.6°"，我一度准备定性为系统缺陷。

### 真实工况（阶跃 15° 保持 1s 后回平，4s）

| 配置 | 保持段最大偏差 | 回平后尾振 | 回平后最大 |
|---|---|---|---|
| **真值姿态（对照）** | **4.81°** | **0.44°** | **0.44°** |
| EKF 补偿关 | 22.66° | 2.33° | 13.11° |
| **EKF 补偿开（GPS差分）** | **11.46°** | 7.90° | **6.17°** |

→ **真实工况下没有"剧烈失稳"**；剩下的是**平移污染造成的估计误差注入控制**
（P4 的 A3 已量化：0.5g 平移下开环姿态误差 14.53°；开补偿后 5.64°）。

### 平移补偿在闭环里的效果

| 指标 | 补偿关 | 补偿开 | 改善 |
|---|---|---|---|
| 保持段最大偏差 | 22.66° | **11.46°** | 49% |
| 回平后最大 | 13.11° | **6.17°** | 53% |

与开环 A3 实测的 52~61% 一致 ✓ —— **开环结论能预测闭环收益**。

### 2.5 判据（已转绿）

`att_ctrl.rs::att_loop_with_estimated_attitude`：**估计驱动的保持段偏差**
应满足 `est < 3.5×truth_baseline + 1°`（真值基线实测 4.81° → 门槛 17.8°，
实测 11.46°）。门槛由**真值基线**推出，不是拍脑袋。
