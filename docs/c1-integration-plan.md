## 1. 适配层（预计很小 ✓）

仿真侧 `ImuSample` 给的是**角速度/比力**（rad/s、m/s² ✓），而 C1 的 `predict` 取**增量** ✓：
```rust
// 适配（一行 ✓）：增量 = 速率 × dt
let delta_ang = [imu.gyro[0].0 * dt, imu.gyro[1].0 * dt, imu.gyro[2].0 * dt];
let delta_vel = [imu.accel[0].0 * dt, imu.accel[1].0 * dt, imu.accel[2].0 * dt];
f.predict(delta_ang, delta_vel, dt, [0.0, 0.0, 9.81]);   // g_ned ✓（NED 下为正 ✓）
```
⚠️ **须先自检**（本会话教训 ✓）：用【静止】场景核对 `predict` 后速度不变 ✓
（与 `c1_extreme_cases` 同一判据 ✓ ⇒ 若不适配，静止就会漂 ✓）
