## F1. 重力锚定把姿态估计变成 ~2Hz 低通（相位滞后 + 幅值衰减）

### 测量方法

单轴正弦（roll），**固定峰值角速率 8°/s**（低于陀螺门斜坡起点 14.3°/s → 门恒开），
扫频 0.1–2Hz。用最小二乘投影提取 `θ̂ ≈ B·sin(ωt+φ_e)`，与真值
`A·sin(ωt+φ_t)` 比较得增益与滞后。A/B 对照：
- **ON**：默认门控
- **OFF**：`G_WGYRO_HI := 1e-6` → `w_gyro≡0` → 锚定恒定关闭

加计一阶低通：`accel_lp += 0.05·(a_raw−accel_lp)` @ dt=4ms
→ `tau = −dt/ln(0.95) = 0.0780s`，`fc = 2.04Hz`。

### 实测

| f (Hz) | ON 增益 | ON 滞后 (°) | ON 滞后 (ms) | **OFF 增益** | **OFF 滞后 (°)** | LPF 理论滞后 (°) |
|---|---|---|---|---|---|---|
| 0.1 | 0.996 | 3.17 | 88.1 | **1.000** | −0.05 | 2.81 |
| 0.2 | 0.989 | 6.18 | 85.8 | **1.000** | −0.09 | 5.60 |
| 0.3 | 0.977 | 9.42 | 87.2 | **1.000** | −0.14 | 8.36 |
| 0.5 | 0.941 | 15.12 | 84.0 | **1.000** | −0.23 | 13.77 |
| 0.7 | 0.885 | 20.34 | 80.7 | **1.000** | −0.31 | 18.93 |
| 1.0 | **0.790** | **27.41** | 76.1 | **1.000** | −0.46 | 26.10 |
| 1.5 | 0.602 | 34.89 | 64.6 | **1.000** | −0.69 | 36.31 |
| 2.0 | 0.424 | 34.77 | 48.3 | **1.000** | −0.91 | 44.42 |

### 结论

1. **锚定 OFF 时增益恒 1.000、滞后恒 0** → 纯陀螺积分路径**零滞后零衰减**。
   **全部退化 100% 来自重力锚定。**
2. 锚定 ON 的滞后与幅值衰减**与加计低通（fc=2.04Hz）高度重合**（1Hz 处
   27.41° vs 理论 26.10°）——即**锚定把估计拉向"滞后的重力参考"**。
3. 幅值衰减**比单极点更快**（2Hz 实测 0.424 vs 单极点 0.714）→ 锚定反馈与陀螺
   积分相互抵消，形成额外二阶滚降。低频等效纯延时 ≈ **86ms**。
4. `att_alpha=0.02`（`k=0.01`/4ms 步 → 锚定自身时间常数 ≈0.4s ≈ 2.5Hz）与加计
   低通截止 **2.04Hz 同量级**，因此**加计参考在 0.1–2Hz 全频段压过陀螺**。

### 分轴对照（决定性证据）

同一次扫频跑三个轴（`att_est.rs::spec_attitude_estimator_frequency_response`）：

| axis | 0.5Hz | 1Hz | 2Hz | 3Hz |
|---|---|---|---|---|
| roll | 0.941 / 15.12° | 0.790 / 27.41° | 0.424 / 34.77° | 0.255 / — |
| pitch | 0.940 / 15.11° | 0.790 / 27.41° | 0.425 / 34.41° | 0.259 / — |
| **yaw** | **1.000 / −0.22°** | **1.000 / −0.46°** | **1.000 / −0.92°** | **1.000 / −1.36°** |

（格式：增益 / 滞后。3Hz 处 roll/pitch 增益仅 0.26，相位已无意义。）

**yaw 走磁锚定，全程透进飞行频段完全不退化。** 两者唯一的结构性差异：

| | 重力锚定（roll/pitch） | 磁锚定（yaw） |
|---|---|---|
| 参考量 | 加速度计，**过 `accel_lp` 低通**（fc≈2.04Hz，`ekf.rs:327`） | 磁力计，**完全不滤波**（`ekf.rs:1073-1104`） |
| 修正轴 | 机体系 `att * dq` | 世界系 `dq * att`（纯 yaw） |
| 门控 | 幅值/方向/陀螺三道 | 无（仅 `mh<1e-3` 健全性） |

→ **滞后不是"锚定"机制的固有属性，而是"参考量被低通"带来的。**

### 机制与修复方向

锚定是反馈：估计 = 陀螺积分 + 锚定修正。平衡态下

```
est ≈ LPF(truth) + (d/dt)(truth − LPF(truth)) / k_eff        k_eff = k/dt = att_alpha·0.5/dt
```

- **低频**（`truth − LPF(truth) → 0`）：第二项 → 0，`est ≈ LPF(truth)`
  → 锚定仍完整校正漂移 ✓
- **高频**：第二项变大，向真值靠拢；`k_eff` 越小靠得越近（陀螺主导）

**但是"降 `att_alpha`"是错的修法**（初稿建议，已推翻）：

实测扫描 `att_alpha` 证明它**治不了本，而且有代价**：

| alpha | 0.5Hz | 1Hz | 2Hz | 3Hz |
|---|---|---|---|---|
| 0.02（现状） | 0.941/+15.1° | 0.790/+27.4° | 0.424/+34.8° | 0.255/— |
| 0.005 | 0.865/+11.8° | 0.684/+9.0° | 0.675/−9.4° | 0.782/−13.8° |
| 0.002 | 0.853/+4.4° | 0.820/−1.3° | 0.874/−6.1° | 0.920/−6.8° |
| 0.001 | 0.903/+0.6° | 0.908/−1.9° | 0.939/−3.7° | 0.961/−4.1° |
| 0 | 1.000/−0.2° | 1.000/−0.5° | 1.000/−0.9° | 1.000/−1.4° |

降 alpha 确实降滞后，但**增益要回到 0.98 就必须 alpha→0**（关掉锚定），
而关闭锚定等于放弃漂移抑制（见 F5：EKF **不估计陀螺零偏**，锚定是**唯一**抗漂机制）。

### 真正的根因与修法（已实施）

根因不是锚定强度，而是**锚定的参考量被多滤了一级**。`ekf.rs:327`：

```rust
let lp_coeff = 0.05f32; // ~20Hz 截止，滤除 40Hz 振动
```

而 `step_hil` 在把 accel 交给 EKF **之前**已完成 40Hz 陷波 + 20Hz 低通。
所以这一级（fc≈2.04Hz）**对抑振冗余**，唯一作用就是制造滞后。

**A/B 实测**（`att_alpha` 保持 0.02 不变，只改 `G_ACCEL_LP`）：

| lp | fc | 0.5Hz | 1Hz | 2Hz | 3Hz |
|---|---|---|---|---|---|
| 0.05（原） | 2.0Hz | 0.941/+15.1° | 0.790/+27.4° | 0.424/+34.8° | 0.255/— |
| 0.2 | 8.9Hz | 0.988/+4.9° | 0.954/+9.4° | 0.839/+16.2° | 0.702/+18.2° |
| 0.5 | 27.6Hz | 0.994/+2.8° | 0.976/+5.3° | 0.916/+9.3° | 0.840/+11.2° |
| **1.0（旁路）** | — | **0.995/+2.1°** | **0.982/+4.0°** | 0.937/+7.0° | 0.881/+8.3° |

**抗振对照**（纯静止悬停 + `vib_amp=1.5 m/s²`@40Hz）：

| lp | 0.05 | 0.1 | 0.2 | 0.5 |
|---|---|---|---|---|
| RMSE | 0.5301° | 0.5311° | 0.5324° | 0.5343° |

→ **抗振完全不受影响**（差 0.8%）。因为上游已有 40Hz 陷波，而锚定自身的
低增益（`k≈0.01`/拍）本身就是低通。

**修复**：`G_ACCEL_LP` 默认 `0.05 → 1.0`（旁路）。**`att_alpha` 未动**
→ 漂移抑制能力不变，**不存在权衡**。

残余滞后（2–3Hz 的 6.95°/8.30°）正好等于 **`step_hil` 上游 20Hz 低通**的
`atan(f/20)`（5.7°/8.5°），不是锚定造成。若要支持 >1Hz 的姿态环带宽，
需另行评估把该低通改为陷波（**不可与本次修复混改**）。

> 对照：磁航向（yaw）锚定因**参考不滤波**而全程透明（增益 1.000、滞后≈0），
> 正是本修复的现成样板。

## F1-SPEC：频响硬门槛 v2（**已转绿**）

判据不是"某频率滞后多少度"，而是 **锚定不得侵入姿态环飞行频段**：

| 频段 | 附加滞后 | 增益 | 理由 |
|---|---|---|---|
| **A** `[0.5, 1.0] Hz` | ≤ 5° | ≥ 0.97 | 姿态环交叉（`att_kp`≈0.48Hz）的 1–2 倍，必须近乎透明 |
| **B** `(1.0, 3.0] Hz` | ≤ 10° | ≥ 0.85 | 受 `step_hil` 上游 20Hz 抗噪低通限制（滞后 `atan(f/20)`） |
| 锚定工作区 `f < 0.2Hz` | 不约束 | 不约束 | 锚定在此工作，滞后无妨 |

**执行**：`att_est.rs::spec_attitude_estimator_frequency_response`（21 项测量）。
修复后结果（roll/pitch 对称，yaw 全程 `1.000/≈0°`）：

| f | 0.5 | 1.0 | 1.5 | 2.0 | 3.0 | 0.1 | 0.2 |
|---|---|---|---|---|---|---|---|
| 增益 | 0.995 | 0.982 | 0.963 | 0.937 | 0.881 | 1.000 | 0.999 |
| 滞后° | 2.07 | 3.96 | 5.62 | 6.95 | 8.30 | 0.43 | 0.83 |

**v1→v2 修订说明**：v1 定为"[0.5,3]Hz 统一 ≤5°/≥0.98"，是未测量时的第一性猜测。
实测发现 2–3Hz 残余滞后（6.95°/8.30°）正好等于**上游 20Hz 低通**的 `atan(f/20)`
（5.7°/8.5°），而非重力锚定造成。该上游低通是为衰减加计白噪声的合法设计，
改它需单独做噪声验证（**不得与本次修复混改**）。故按"实测可达包线 + 明确归因"
分两段：飞行频段收紧，2–3Hz 放宽并标注真实限制源。

**背景**：作者计划把姿态环带宽从当前 `att_kp=3.0 rad/s ≈ 0.48Hz` 继续上调，
所以本项必须在提带宽之前修掉（已完成）。若要支持 >1Hz 带宽，还需处理上游 20Hz 低通。

## F2. 门控参数实际值（`ekf.rs:332-394`）

```
幅值门 w      : |a|/g ∈ [0.5, 2.5] 外 → 0；内线性
方向门 w_align: cos(夹角) < 0.90 → 0；0.90→1.00 线性（阈值 G_WALIGN_COS）
陀螺门 w_gyro : |ω| < 0.25 rad/s → 1；0.25→0.6 线性降到 0；> 0.6 → 0
                 （G_WGYRO_HI 默认 0.6，斜坡下限 g_lo = g_hi·(0.25/0.6)）
k = att_alpha · 0.5 · w · max(w_align·w_gyro, w_floor)
```

**注意**：陀螺门的**斜坡起点是 0.25 rad/s = 14.3°/s**，不是 0.6 rad/s（34°/s）。
34°/s 只是降到 0 的终点。

## F5. 【已修】磁航向锚定在整条 `step_hil` 链路静默失效（yaw 无任何绝对参考）

**发现时机**：在写 F1 的"漂移面回归"时发现 yaw 漂移量**精确等于 `bias_z × t`**
（静态 40s、`b_z=0.004 rad/s` → 9.17°），即**零校正**。

### 根因

`EkfEstimator` 的 `update_mag` 实现在 **固有 impl**（`ekf.rs` 尾部"非 trait 方法"区），
而 `impl Estimator for EkfEstimator` 里**没有**对应委托：

```rust
// trait impl 里有（正确模式）
fn update_alt(&mut self, alt: f32) { EkfEstimator::update_alt(self, alt); }

// —— update_mag 没有！——
```

`HilContext<E: Estimator, C>` 持有**泛型参数**，方法解析只看 trait 方法 → 命中
`trait_def.rs` 的默认空实现：

```rust
fn update_mag(&mut self, _mag: Option<[f32; 3]>) {}   // no-op
```

→ 磁锚定在 **SIL / HIL / MCU 固件**全部静默失效，**yaw 退化为纯陀螺积分**。

### 为何长期未被发现

1. **EKF 单测直接对具体类型调** `ekf.update_mag(...)`（`ekf.rs:1204/1215/1230/…`）
   → 命中固有方法 → 测的是正确实现 → **全绿**。
2. **集成测试用 `SensorConfig::default()`**（`gyro_bias = [0,0,0]`）→ yaw 本就不漂
   → `mag_hover.rs` 那句"yaw 应被磁航向锚定到 0" **空过**。
3. **没有任何测试**在"有陀螺零偏"下断言 yaw **绝对**锚定。
   （`x_env_motion::turn_yaw_rate_tracks` 只查 yaw **速率**，纯陀螺就能过。）

典型"单测过了、集成没接上"。

### 修复

在 trait impl 里补上委托（与 `update_alt` 同模式）：

```rust
fn update_mag(&mut self, mag: Option<[f32; 3]>) {
    EkfEstimator::update_mag(self, mag);
}
```

### 实测效果（静态 40s，陀螺零偏 `[0.01,0.008,0.004]` rad/s）

| | roll | pitch | yaw |
|---|---|---|---|
| 修复前（经 `step_hil`） | 0.02° | 0.02° | **9.17°→无界漂移** |
| 修复后 | 0.02° | 0.02° | **0.08°** |
| 锚定 OFF（对照） | 13.69° | 11.96° | 39.88° |

### 连带修正的测试

- `hil.rs::hil_step_hil_loop_runs_and_stays_bounded`：原本注入**恒定机体系磁场**
  `[0.2,0,0.4]`（等价于磁场随飞行器一起转，**物理不成立**）却断言 `yaw≈0.7`。
  锚定失效时"恰好"能过。已改为**按真值姿态生成机体磁场**。
- `att_est.rs` 的 `low_noise()`：原本继承 `realistic()` 的硬铁 `[0.3,-0.2,0.4]`，
  锚定生效后 yaw 被稳定在偏 22° 的航向 → 已清零（硬铁属阶段 6）。

### 新的待办（发现自本 bug）

- **磁锚定无陀螺门控**（重力锚有三道门，磁锚一道也没有）。持续大角速率偏航下
  它会持续向磁北拉——需在阶段 6 评估是否要给磁锚也加 `w_gyro`。
- **EKF 无磁硬铁状态**：`realistic()` 硬铁 `[0.3,-0.2,0.4]` 实测造成 **22° yaw 恒定偏差**
  （有界，但航向错）。属阶段 6（鲁棒性）课题。
- **`mag_hover.rs` 空过**：需改成带非零陀螺零偏才能真正验证磁锚定。

## F6. 协调转弯的 bank 对加速度计不可观 → 重力锚定方向门死锁（测试台缺陷）

**背景**：F5 修好后，M 场 `x_env_motion::turn_yaw_rate_tracks` 回归（累计 Euler yaw
旋转变成 **−1.35 rad**）。经与 F1（lp 修复）、场景改动三次二分 + 诊断打印定位。

### 诊断数据（M 场，打印估计 vs 真值）

```
step |  估计(r,p,y)°       |  真值(r,p,y)°       | est ω               | truth ω
   0 | ( 0.00, 0.00,   0.00) | ( 0.01, 0.00,   0.37) | (0.000,0.000,0.000) | (0.039,0.000,0.500)
 100 | ( 2.59, 2.61,  16.61) | (29.20, 0.00,  37.61) | (0.000,0.244,0.436) | (0.000,0.244,0.436)
 499 | ( 2.33, 1.95,-133.83) | (29.20, 0.00, 186.21) | (0.000,0.244,0.436) | (0.000,0.244,0.436)
```

**`est.omega ≡ truth.omega`（逐位一致）→ 陀螺通路完美**；
但 **估计 roll 停在 2.33°，真值 29.20°** → bank 从未建立。

### 机制：闭环死锁

1. 协调转弯下比力沿机体 −z：`a_body = R^T(a_world−g) = [0, 0, −g/cosφ]`
   （推导：`a_world = g·tanφ·[−sinψ, cosψ, 0]`，经 `R^T = Rx(−φ)Rz(−ψ)` 旋转后
   得 `[0, g tanφ, −g] → [0, 0, −g/cosφ]`）→ **加速度计看不到 bank**。
2. `step_hil` 用加速度计做倾角对准 → **EKF 初值水平**。
3. 重力锚定**方向门**在 `bank < 25.8°` 时开启 → 把估计 roll 拉回水平。
4. bank 因此永远长不到 25.8° → **门永不关闭 → 死锁**。

估计姿态停在“水平偏航”，与带 29° bank 的真值**不可比**：
Euler yaw 变化率 `ψ̇ = (q·sinφ + r·cosφ)/cosθ` 在 φ 不同时**连符号都会反**。

### 为何此前“通过”

F5：`EkfEstimator` 缺 `Estimator::update_mag` 的 trait 委托 → 磁锚定静默失效
→ 估计纯陀螺积分，Euler yaw 恰好正向累积。测试注释本身就写着
“此为场景构造局限，不断言 roll 精确值，只断言不发散”——只是没意识到
**yaw 累计量同样受这个不可观自由度支配**。

### 处理

`x_env_motion::turn_yaw_rate_tracks` 改为断言**可观测量**：

| 断言 | 实测 |
|---|---|
| `est.omega` 跟踪真值（新增 `max|Δω|`） | 0.0009 rad/s |
| 姿态有界、FDIR 健康 | max\|roll\|=2.2° |
| yaw **在转**（只看 \|累计\|，不看方向） | 1.29 rad |
| 位置沿圆周推进 | 39.9 m |

**不再断言 Euler yaw 累计旋转量**——它测的是不可观自由度，不是估计器缺陷。

### 遗留（待决策）

- `EnvScenario::Motion::Turn` 的真值本身**不自洽**：`att` 带 29° 恒定 bank，

### 发现的真问题 ①：`Maneuver::Turbulence` 真值不物理（我的 bug）

升级后 A8 直接**发散**：rms=10°/band=3Hz → RMSE **130.9°**。逐层定位：

1. **不是锚定**：关掉重力锚后一样差（113°）。
2. **不是 EKF 积分**：同 `max|ω|` 的**光滑正弦**只有 **1.9°**（1513°/s）！

| 激励 | max|ω| | RMSE |
|---|---|---|
| 正弦 3Hz amp=80° | 1513°/s | **1.92°** |
| 正弦 3Hz amp=120° | 2270°/s | **2.93°** |
| 噪声 rms=20° band=3Hz | 1552°/s | **117.81°** |

⇒ 根因：`Turbulence` 对**白噪声**做**一级**低通得 euler，再由 `from_maneuver`
**差分**出 ω。差分会把低通的 −20dB/dec 抵消 ⇒ **ω 频谱延伸到 Nyquist**，
与光滑的 q **不自洽**；EKF 按 4ms 采样那个抖动 ω 积分就走另一条姿态轨。

**修法**：改**两级低通** ⇒ ė 自身的频谱在 Nyquist 前已衰减。A8 从 117.8° → **1.573°**。

**回归守卫**：`a8` 内新增“同 max|ω|，光滑正弦 vs 带限噪声”对照，断言
`噪声 RMSE < 10°`（真值 bug 时是 130.9°，正常是 4.05°）。

### 发现的真问题 ②：测试旋钮跨测试泄漏（flaky）+ 产品默认值有害

将强度升级后，并行跑出现 **3 次挂 1 次**的 flaky。定位：`G_AW_GPS` 静态初值
**1.0（开）**，而 `a3e` 收尾把它置为 **0.0（关）** 泄漏给后续；依赖“环境默认开”的
`a3` 就变成无补偿 → 改善≈0 → 挂。

修法：`lock()` 在取锁时统一重置为**测试基线**，并且 `a3` **显式**打开。
纪律：**本文件任何测试不得依赖环境遗留状态**。
